Privacy Policy

Last updated: August 13, 2026

BYD Dashcam stores all data exclusively on the vehicle device. No personal information is transmitted to external servers. Third-party integrations (Telegram, MQTT) are entirely optional and user-configured.

1. Data We Access

The following describes what data the app accesses on your device and why.

Data Type Purpose Storage
Camera video (front, rear, left, right) Dashcam recording On-device only
GPS location & speed Speed overlay, GPX track file On-device only
Accelerometer data Impact detection (parking guard) Processed in memory only — never stored
Telegram Bot Token & Chat ID Sending impact/motion alert notifications On-device only Optional
MQTT credentials (host, port, username) Publishing to Home Assistant or other MQTT brokers On-device only Optional
Phone app PIN Authenticating remote Wi-Fi access On-device only

2. How Data Is Used and Retained

  • Video recordings and GPX files are stored only in the user-specified location on the vehicle's internal storage.
  • Accelerometer data is used solely for impact detection calculations and is never written to disk.
  • Settings (Telegram token, MQTT credentials, etc.) are saved in Android SharedPreferences and are deleted when the app is uninstalled.
  • The app developer has no access to any user data at any time.

3. Third-Party Services

The services below are used only when explicitly enabled by the user. If not enabled, no external network connections are made.

  • Telegram — Sends impact and motion event notifications to a user-specified chat. Telegram's Privacy Policy applies.
  • MQTT Broker — Publishes GPS, battery, and event data to a user-specified broker. The broker operator's policy applies.
  • Cloudflare Tunnel — When enabled for external phone access, the cloudflared binary is downloaded from Cloudflare. Cloudflare's Privacy Policy applies.

4. Remote Phone Access

When the phone app (iOS/Android) connects to the vehicle app:

  • The connection is made over the same Wi-Fi network (or Cloudflare Tunnel) and requires PIN authentication.
  • Data transmitted to the phone is limited to the live camera preview stream and the recording file list.
  • The phone app requires no account and sends no data to any server.

5. Permissions Required

Permission Why It's Needed
CAMERA Accesses the vehicle's built-in AVM cameras to record video.
ACCESS_FINE_LOCATION Reads GPS speed and coordinates for the video overlay and GPX track.
FOREGROUND_SERVICE Keeps recording running in the background even when the screen is off.
INTERNET, ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE Used for phone app connectivity and optional Telegram/MQTT/Cloudflare integrations. No external traffic when these features are disabled.
RECEIVE_BOOT_COMPLETED Automatically starts recording when the vehicle powers on.
REQUEST_IGNORE_BATTERY_OPTIMIZATIONS Prevents Android from force-stopping background recording.

6. Data Security

  • All recordings are created and managed directly by the app on the vehicle's internal storage.
  • Remote phone access requires a 4-digit PIN.
  • When Cloudflare Tunnel is enabled, all traffic is encrypted over HTTPS.
  • The app's source code is published under the MIT license and is open for anyone to inspect.

7. Children's Privacy

This app is a tool for vehicle drivers and passengers. It is not directed at children under the age of 13, and we do not knowingly collect personal information from children.

8. Changes to This Policy

Any changes to this policy will be published in the GitHub repository with an updated date. Material changes will be noted in the release notes.
