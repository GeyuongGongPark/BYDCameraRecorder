개인정보 처리 방침

최종 수정일: 2026년 8월 13일

BYD 블랙박스 앱은 모든 데이터를 차량 기기 내부에만 저장합니다. 외부 서버로 개인정보를 전송하지 않으며, 사용자가 직접 설정한 외부 서비스(Telegram, MQTT) 연동은 선택 사항입니다.

1. 수집하는 정보

앱이 기기에서 접근하는 데이터와 그 목적은 다음과 같습니다.

데이터 종류 목적 저장 위치
카메라 영상 (전·후·좌·우) 블랙박스 녹화 기기 내부
GPS 위치·속도 속도 오버레이, GPX 트랙 저장 기기 내부
가속도계 데이터 충격 감지 (주차 감시 모드) 메모리에서만 처리, 저장 안 함
Telegram Bot Token · Chat ID 충격/모션 감지 알림 전송 기기 내부 선택
MQTT 접속 정보 (호스트·포트·계정) Home Assistant 등 MQTT 브로커 연동 기기 내부 선택
폰 앱 PIN Wi-Fi 원격 접속 인증 기기 내부

2. 정보의 이용 및 보관

  • 녹화 영상과 GPX 파일은 사용자가 지정한 차량 내부 저장소에만 보관됩니다.
  • 가속도계 데이터는 충격 감지 계산에만 사용되며 저장되지 않습니다.
  • 설정값(Telegram 토큰, MQTT 계정 등)은 Android SharedPreferences에 저장되며 앱을 제거하면 함께 삭제됩니다.
  • 앱 개발자는 어떤 사용자 데이터에도 접근할 수 없습니다.

3. 제3자 서비스

아래 서비스는 사용자가 직접 활성화한 경우에만 사용됩니다. 활성화하지 않으면 어떤 외부 연결도 발생하지 않습니다.

  • Telegram — 충격·모션 이벤트 알림 메시지를 사용자가 지정한 Chat으로 전송합니다. Telegram의 개인정보 처리 방침이 적용됩니다.
  • MQTT 브로커 — GPS, 배터리, 이벤트 데이터를 사용자가 지정한 브로커에 발행합니다. 브로커 운영자의 방침이 적용됩니다.
  • Cloudflare Tunnel — 폰 앱 외부 접속을 위해 사용자가 활성화한 경우 cloudflared 바이너리를 다운로드합니다. Cloudflare의 개인정보 처리 방침이 적용됩니다.

4. 폰 앱 원격 접속

폰 앱(iOS/Android)이 차량 앱에 접속할 경우:

  • 접속은 동일 Wi-Fi 네트워크 또는 Cloudflare 터널을 통해 PIN 인증 후 이루어집니다.
  • 폰으로 전송되는 데이터는 카메라 스트리밍 프리뷰와 녹화 파일 목록에 한정됩니다.
  • 폰 앱은 별도의 계정 없이 동작하며, 서버로 어떤 데이터도 전송하지 않습니다.

5. 필요 권한

권한 사용 목적
CAMERA 차량 내장 AVM 카메라에 접근하여 영상을 녹화합니다.
ACCESS_FINE_LOCATION GPS 속도·위치 정보를 가져와 오버레이와 GPX 트랙에 사용합니다.
FOREGROUND_SERVICE 화면이 꺼져도 백그라운드에서 녹화를 계속하기 위해 사용합니다.
INTERNET, ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE 폰 앱 연결 및 Telegram/MQTT/Cloudflare 외부 서비스 연동에 사용합니다. (해당 기능 비활성화 시 외부 통신 없음)
RECEIVE_BOOT_COMPLETED 차량 시동 시 자동 녹화 시작을 위해 부팅 완료 이벤트를 수신합니다.
REQUEST_IGNORE_BATTERY_OPTIMIZATIONS 백그라운드 녹화가 Android에 의해 강제 종료되지 않도록 배터리 최적화 예외를 요청합니다.

6. 데이터 보안

  • 녹화 영상은 차량 내부 저장소에 저장되며, 앱이 직접 생성·관리합니다.
  • 폰 앱 접속 시 4자리 PIN 인증이 필요합니다.
  • Cloudflare 터널 사용 시 HTTPS로 암호화되어 전송됩니다.
  • 앱 코드는 MIT 라이선스 하에 오픈소스로 공개되어 있어 누구나 검토할 수 있습니다.

7. 아동의 개인정보

이 앱은 차량 운전자 및 탑승자를 위한 도구로, 만 14세 미만 아동을 대상으로 하지 않습니다. 아동으로부터 의도적으로 정보를 수집하지 않습니다.

8. 방침 변경

이 방침이 변경될 경우 GitHub 저장소에 업데이트된 날짜와 함께 공개합니다. 중요한 변경사항은 릴리즈 노트에 명시합니다.
