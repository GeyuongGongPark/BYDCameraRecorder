완전한 블랙박스를

BYD 차량의 내장 AVM 카메라를 활용한 무설치 블랙박스 앱. 4채널 360° 녹화, GPS 속도 오버레이, 이벤트 프리버퍼, Telegram·MQTT 알림을 지원합니다.

핵심 기능

블랙박스에 필요한 모든 것

별도 장치 없이 BYD 내장 카메라만으로 전방위 블랙박스를 구현합니다.

🎥

4채널 360° 녹화

전·후·좌·우 4개 카메라를 동시에 H.264 MP4로 녹화합니다. 개별 영상과 2×2 합성 영상을 함께 저장합니다.

📍

GPS 속도 오버레이

영상에 현재 속도(km/h·mph 선택)를 직접 새겨 넣습니다. GPX 트랙 파일도 함께 저장되어 경로 재생이 가능합니다.

🛡️

주차 감시 · 모션 감지

가속도계(기본 2.5G)와 카메라 프레임 비교로 충격·움직임을 감지하면 즉시 녹화를 시작합니다. 감도(1~5단계) 조절 가능합니다.

⏮️

이벤트 프리버퍼

주차 대기 중 12초 단위 슬라이딩 버퍼를 유지합니다. 충격·모션 감지 시 직전 세그먼트를 함께 잠금 처리해 사고 전 영상을 보존합니다.

🔄

연속 루프 녹화

세그먼트(기본 3분) 단위로 순환 녹화합니다. 용량 한도에 도달하면 오래된 영상부터 자동으로 삭제합니다.

📱

폰 앱 원격 접속

같은 Wi-Fi의 iOS·Android 폰에서 실시간 카메라 프리뷰, 영상 다운로드, 주차 감시 토글이 가능합니다. Cloudflare 터널로 외부 접속도 지원합니다.

🔔

Telegram 알림

충격·모션 감지 시 Telegram 봇으로 즉시 알림을 받습니다. Bot Token과 Chat ID만 입력하면 설정 완료입니다.

🏠

MQTT · Home Assistant

GPS, 배터리, 충격 이벤트를 MQTT 브로커에 발행합니다. Home Assistant MQTT Discovery를 지원해 자동으로 센서가 등록됩니다.

⚡

차량 시동 시 자동 시작

BOOT_COMPLETED 브로드캐스트를 수신해 차량이 켜지면 자동으로 녹화를 시작합니다. 별도 조작이 필요 없습니다.

사용 방법

설치부터 녹화까지 4단계

별도 하드웨어 설치 없이 APK 설치만으로 바로 사용할 수 있습니다.

1

APK 설치

Releases 페이지에서 최신 APK를 다운로드하여 차량 인포테인먼트 시스템에 설치합니다.

2

권한 허용

앱 최초 실행 시 카메라 및 위치 권한을 허용합니다. 저장 경로와 녹화 시간 등을 설정합니다.

3

자동 녹화 시작

차량 시동을 켜면 자동으로 녹화가 시작됩니다. 주차 후 감시 모드를 켜면 충격·모션 감지 시 자동 녹화됩니다.

4

폰으로 확인

폰 앱으로 Wi-Fi 접속해 실시간 프리뷰와 이벤트 영상을 확인합니다. Telegram으로 충격 알림도 받을 수 있습니다.
